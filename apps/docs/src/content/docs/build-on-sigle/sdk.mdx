## Installation

```bash
npm install @sigle/sdk
```

## Verify metadata signature

To verify the cryptographic signature of metadata (posts or profiles), use the `verifyMetadataSignature` function. It returns a typed `Result` from `better-result` containing the recovered Stacks address, public key, and signature on success, or an `InvalidSignatureError` on failure.

> **Important**: `verifyMetadataSignature` verifies that the metadata was signed and recovers the signer's Stacks address. You must always check that `recoveredAddress` matches the expected author's address to ensure the post was signed by the intended author.

```tsx
import { verifyMetadataSignature } from "@sigle/sdk";

const result = verifyMetadataSignature(postMetadata, {
  // Optional: defaults to "mainnet". Can also be "testnet", "devnet", or "mocknet".
  network: "mainnet",
});

if (result.isErr()) {
  console.error("Invalid signature:", result.error.message);
  return;
}

const { recoveredAddress, publicKey, signature } = result.value;

// Ensure the recovered address matches the expected post author

  console.error("Author mismatch: post was not signed by the expected author");
  return;
}

console.log("Verified post author:", recoveredAddress);
```
