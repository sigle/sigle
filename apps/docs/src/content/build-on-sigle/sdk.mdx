# @sigle/sdk

## Installation

```bash
npm install @sigle/sdk
```

## Create client

To create a client, use the `createClient` method. Pass in the network you want to use.

```tsx
import { STACKS_MAINNET } from "@stacks/network";
import { createClient } from "@sigle/sdk";

const sigleClient = createClient({
  network: STACKS_MAINNET,
});
```

## Mint

To prepare a mint transaction, use the `mint` method. Then pass the parameters to `stx_callContract` to execute the transaction with the user's wallet.

```tsx
import { STACKS_MAINNET } from "@stacks/network";
import { request } from "@stacks/connect";
import { createClient } from "@sigle/sdk";

const sigleClient = createClient({
  network: STACKS_MAINNET,
});

const { parameters } = await sigleClient.mint({
  // Your user sender address
  sender: "SP2X0TZ59D5SZ8ACQ6YMCHHNR2ZN51Z32E2CJ173",
  // Address of the NFT post contract
  contract: "SP2X0TZ59D5SZ8ACQ6YMCHHNR2ZN51Z32E2CJ173.xxx",
  // Amount of tokens to mint
  amount: 1,
  // Optionally, set a referral address to receive the referral fee
  referral: "SP2X0TZ59D5SZ8ACQ6YMCHHNR2ZN51Z32E2CJ173",
  // Price of 1 NFT
  price: post.minterFixedPrice.price,
});

const response = await request("stx_callContract", {
  ...parameters,
  // Your other options
});
```

## Publish post

To deploy a new post, use the `generatePostContract` method to get the smart contract code. Then pass the parameters to `stx_deployContract` to execute the transaction with the user's wallet.

```tsx
import { STACKS_MAINNET } from "@stacks/network";
import { request } from "@stacks/connect";
import { createClient, createPostMetadata } from "@sigle/sdk";
import { createId } from "@paralleldrive/cuid2";

const sigleClient = createClient({
  network: STACKS_MAINNET,
});

// Generate a unique post ID
const postId = createId();

const metadata = createPostMetadata({
  // Add all the metadata fields here
  name: "Your post title",
});

// Upload the post metadata on the storage of your choice (IPFS, Arweave, etc.)
const metadataUrl = await uploadMetadata({
  metadata,
});

const { contract } = sigleClient.generatePostContract({
  metadata: metadataUrl,
  collectInfo: {
    amount: 0,
    maxSupply: 100,
  },
});

const response = await request("stx_callContract", {
  name: postId,
  clarityCode: contract,
  // Your other options
});
```

## Verify post signature

To verify the cryptographic signature of post metadata, use the `verifyPostSignature` function. It returns a typed `Result` from `better-result` containing the recovered Stacks address, public key, and signature on success, or an `InvalidSignatureError` on failure.

> **Important**: `verifyPostSignature` verifies that the metadata was signed and recovers the signer's Stacks address. You must always check that `recoveredAddress` matches the expected author's address to ensure the post was signed by the intended author.

```tsx
import { verifyPostSignature } from "@sigle/sdk";

const result = verifyPostSignature(postMetadata, {
  // Optional: defaults to "mainnet". Can also be "testnet", "devnet", or "mocknet".
  network: "mainnet",
});

if (result.isErr()) {
  console.error("Invalid signature:", result.error.message);
  return;
}

const { recoveredAddress, publicKey, signature } = result.value;

// Ensure the recovered address matches the expected post author
if (recoveredAddress !== expectedAuthorAddress) {
  console.error("Author mismatch: post was not signed by the expected author");
  return;
}

console.log("Verified post author:", recoveredAddress);
```

## OpenTimestamps (OTS)

[OpenTimestamps](https://opentimestamps.org/) provides trustless, decentralized timestamping anchored directly into the Bitcoin blockchain. `@sigle/sdk` includes native, universal OpenTimestamps utilities that work across Node.js, browsers, and edge environments without any external binary dependencies.

### Stamp content

To create a timestamp commitment for any file, string, or binary data, use `stamp` (or `stampWithFallback`). It calculates the SHA-256 digest of your content and submits it to public calendar servers with automatic sequential fallback.

```tsx
import { stamp } from "@sigle/sdk";

// Pass a string or Uint8Array/Buffer
const content = "My blog post content...";
const result = await stamp(content);

if (result.isErr()) {
  console.error("Stamping failed:", result.error.message);
  return;
}

// Stamped pending OTS proof as Uint8Array
const pendingProof = result.value;
```

You can also customize the agenda pool URLs or request timeout:

```tsx
import { stamp } from "@sigle/sdk";

const result = await stamp(content, {
  agendas: [
    "https://a.pool.opentimestamps.org",
    "https://b.pool.opentimestamps.org",
  ],
  timeoutMs: 10000,
});
```

### Check if proof is upgraded

When a timestamp is newly created, it is in a `PENDING` state until the calendar server batches commitments and commits them into a Bitcoin block. Use `isOtsProofUpgraded` to check if a proof is fully anchored into Bitcoin:

```tsx
import { isOtsProofUpgraded } from "@sigle/sdk";

const isUpgraded = isOtsProofUpgraded(proofBuffer);
console.log("Anchored in Bitcoin:", isUpgraded);
```

### Upgrade pending proof

Once the calendar server anchors the batch into a Bitcoin block (typically within 1–2 hours), upgrade the pending proof with `upgradeOtsProof`:

```tsx
import { upgradeOtsProof } from "@sigle/sdk";

const result = await upgradeOtsProof(pendingProof);

if (result.isErr()) {
  console.error("Upgrade failed:", result.error.message);
  return;
}

const { upgraded, proof } = result.value;

if (upgraded) {
  console.log("Proof successfully upgraded with Bitcoin attestation!");
  // Save or upload the upgraded proof (.ots file)
} else {
  console.log("Proof is still pending Bitcoin block inclusion. Retry later.");
}
```

### Verify OTS proof

Use `verifyOtsProof` to validate the integrity of an OTS file and confirm that it matches expected content or a specific SHA-256 hash:

```tsx
import { verifyOtsProof } from "@sigle/sdk";

const verifyResult = verifyOtsProof(proofBuffer, content);

if (verifyResult.isErr()) {
  console.error("Proof verification failed:", verifyResult.error.message);
  return;
}

const { hash, upgraded, verified } = verifyResult.value;
console.log("Verified proof for hash:", hash, "Upgraded:", upgraded);
```
